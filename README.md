# VF_Motor_Driver

**VF_Motor_Driver** is an open hardware power distribution board, designed to be part of a larger modular system.  
This design is **based in part** on the [OpenFFBoard TMC4671 driver board](https://github.com/Ultrawipf/OpenFFBoard-hardware), licensed under the GNU General Public License version 3 (GPLv3).

This repository contains the complete schematic and PCB layout for the VF_Motor_Driver board.

## 🔌 Compatibility

The VF_Motor_Driver is designed to interface with a microcontroller unit (MCU) that is electrically and functionally compatible with the [OpenFFBoard](https://github.com/Ultrawipf/OpenFFBoard) open-source project.

> The OpenFFBoard firmware and hardware are **not included** in this repository  
> and are released under the [MIT License](https://opensource.org/licenses/MIT).

Compatible with OpenFFBoard, but **designed, tested, and supported by VirtualFly** for professional use cases.

This compatibility is provided as a convenience for developers and users who already rely on the OpenFFBoard ecosystem or wish to integrate the VF_Motor_Driver into similar setups.
